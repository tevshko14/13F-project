Features

Everything you need to follow institutional money flow, from portfolio tracking to alternative data signals.

📈

S&P 500 Heatmap

Interactive treemap with daily performance by sector. Gold borders highlight stocks held by superinvestors.

🔍

Fuzzy Ticker Search

Fuse.js-powered autocomplete across ~8,000 NYSE/NASDAQ listings, weighted by superinvestor holdings.

📊

Analyst Ratings

Wall Street consensus with firm-level upgrades, downgrades, and price targets from Finnhub + yfinance.

📣

Market Sentiment

CNN Fear & Greed Index, Finnhub news sentiment, Reddit buzz from ApeWisdom, and Alpha Vantage NLP.

👥

Employee Vitals

Glassdoor ratings, People Data Labs headcount, and App Store ratings — alternative data for fundamentals.

🔔

Real-Time Alerts

SSE-powered notifications when new filings match your watchlist. Star any ticker for instant tracking.

💰

Grand Portfolio

Aggregated view of all 84 superinvestor holdings ranked by conviction — see what the smart money agrees on.

📝

Insider Trading

Recent Form 4 insider transactions showing executive buys and sells alongside institutional activity.

⚡

Smart Caching

Stale-while-revalidate with per-fund TTL. 7-day off-season, 12-hour during filing season. Never blocks on API calls.

Stock Page Deep Dive

Every stock page has 7 tabs of rich data, all lazy-loaded for instant navigation.

Environment Variables

All optional. The dashboard works out of the box with SEC data. Add API keys for richer data.

Variable Provider Free Tier Powers
FINNHUB_API_KEY Finnhub 60/min News sentiment + analyst ratings
ALPHAVANTAGE_API_KEY Alpha Vantage 25/day NLP news sentiment analysis
GLASSDOOR_RAPIDAPI_KEY RapidAPI 25/month Glassdoor culture ratings
PDL_API_KEY People Data Labs 100/month Employee headcount data
App Store Apple iTunes No key needed iOS app ratings + reviews

Quick Start

# Install dependencies
uv sync

# Run the web dashboard
uv run filings-web
# Open http://localhost:8000

# CLI commands
uv run filings search "Berkshire"
uv run filings holdings 1067983
uv run filings compare 1067983
